Vocab-APP

First Commit 24/09/2026

A dynamic vocabulary learning application built with Next.js, React, TypeScript, and Tailwind CSS. The app helps users practice vocabulary by matching words with their corresponding meanings fetched in real-time.

Tech StackFramework: Next.js (App Router)   Language: TypeScript   Styling: CSS / PostCSS   Data Source: Google Sheets (CSV Export)

Prerequisites
Node.js (v18 or higher recommended)
